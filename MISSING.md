# Files not in this repository

## Originals

Every one of the 536 tasks has an `original/` folder with its prompt, grader guidance, grading settings, inputs and
reference files as QA saw them. No task is missing its original.

## Raw public release files

`original/` is the task as ported to our harness (see README, "What original means"), not the raw public
release. The raw files are at the official sources linked in the README.
